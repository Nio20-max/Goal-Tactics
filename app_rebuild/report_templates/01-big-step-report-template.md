# Big Step Report Template

Use this template after every big step.

## Filename

`YYYY-MM-DD-phaseX-step-name.md`

Example:

`2026-03-07-phase1-runtime-capture-pass.md`

## Template

```md
# Big Step Report

Date:
Phase:
Step name:

## Goal

What this step was supposed to achieve.

## Inputs Used

- list exact files, artifacts, and tools used

## Work Performed

- summarize what was actually done
- distinguish static analysis, runtime capture, implementation, and validation

## Outputs Produced

- list generated files, artifacts, screenshots, notes, or code outputs

## What Worked

- list confirmed successful outcomes

## What Failed Or Remains Unclear

- list failures, uncertainties, and unresolved items

## Fallback Used

- none, or describe which fallback path was used and why

## Evidence

- list exact repo files or artifacts that support the conclusions

## Next Actions

- ordered next steps for the following milestone
```
