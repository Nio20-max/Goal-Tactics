# Phase Completion Report Template

Use this template at the end of every numbered phase.

## Filename

`YYYY-MM-DD-phaseX-completion.md`

Example:

`2026-03-07-phase2-completion.md`

## Template

```md
# Phase Completion Report

Date:
Phase:
Phase title:

## Objective

State the official objective of the phase.

## Checklist Status

- completed items
- skipped items
- deferred items

## Deliverables Produced

- list all outputs created in this phase

## Validation Performed

- describe how outputs were checked

## Confirmed Findings

- facts directly supported by evidence from this phase

## Inferences

- conclusions that are likely but not fully proven

## Open Problems

- blockers and unresolved parity questions

## Fallback Paths Used

- none, or describe which fallback sections were used

## Decision Gate

- can the next phase start
- if yes, what are the starting inputs
- if no, what must be fixed first

## Evidence

- exact files, screenshots, scripts, outputs, or code references used as support

## Next Phase Preparation

- list the first concrete steps for the next phase
```
