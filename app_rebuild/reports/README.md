# Reports Folder

This folder stores generated execution reports.

## Rules

- Every big step must produce a report.
- Every numbered phase must produce a completion report.
- Reports must be written before the next major phase begins.

## Naming

- Big step: `YYYY-MM-DD-phaseX-step-name.md`
- Phase completion: `YYYY-MM-DD-phaseX-completion.md`
- Blocker report: `YYYY-MM-DD-phaseX-blocker-name.md`

## Minimum Required Reports

- one report at the end of Phase 0
- one report at the end of Phase 1
- one report at the end of Phase 2
- one report at the end of Phase 3
- one report at the end of Phase 4
- one report at the end of Phase 5
- one report at the end of Phase 6
- one report at the end of Phase 7
- one report at the end of Phase 8
- one report at the end of Phase 9

- runtime capture pass report
- shell milestone report
- shared component bundle report
- feature group report
- realtime integration report
- first visual diff pass report
- beta readiness report
